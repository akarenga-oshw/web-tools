ブートモードへの入り方と既知の注意点

USB ブートモード: MD ピンを Low に落としたままリセット解除 → USB を接続。045B:0261 "RA USB Boot" として列挙されます。ボーレート・パリティは CDC 上では無視されるので、同期シーケンスなしで Inquiry から始められます。

SCI ブートモード: MD=Low でリセット解除後、9600 8N1 で 0x00 を 2 回 → ACK 0x00、0x55 → ブートコード 0xC3。応答がない場合はパリティ ODD で同期し、0xC3 受信後に NONE へ切り替えます（RA2 系で確認されている挙動。RA4M1 では通常 NONE のままで通ります）。

Windows: RA USB Boot が usbser.sys に紐づいていないと Web Serial からポートが見えません。デバイスマネージャで COM ポートとして出ているか先に確認してください。

ID 認証: ID コードが書かれた個体では Inquiry が Flow error (0xC3) を返します。このツールは FF×16 で自動認証を試みます。
